How the DIFF and PG_ERR statements were triaged:
- grouped by root cause, with examples checked on both servers;
- the rest set aside as noise: cascades from tables or rows the frontend could not create, the runner's added

- documented limits set aside too: constraints, DDL in transactions, savepoints, isolation levels, serial.
